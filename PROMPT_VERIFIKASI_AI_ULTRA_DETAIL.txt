1.1 TUJUAN UTAMA SISTEM
------------------------
Membangun sistem verifikasi selfie kehadiran mahasiswa berbasis Artificial Intelligence
yang mampu:
- Memproses data REAL dari database (TIDAK BOLEH DUMMY DATA)
- Melakukan analisis biometrik wajah secara mendalam
- Mendeteksi fraud dan kecurangan dengan akurasi tinggi
- Memberikan rekomendasi keputusan verifikasi otomatis
- Menyediakan audit trail lengkap untuk setiap verifikasi

1.2 PRINSIP DESAIN
------------------
A. DATA INTEGRITY
   - Semua data HARUS diambil langsung dari database production
   - Tidak ada hardcoded values atau dummy data
   - Setiap field kosong sebelum AI scan, terisi setelah scan
   - Data historical harus akurat dan traceable

B. REAL-TIME PROCESSING
   - AI processing time bervariasi (9-16 detik) sesuai kompleksitas
   - Progress indicator real-time untuk setiap step
   - WebSocket/SSE untuk update status tanpa refresh
   - Queue system untuk handle multiple requests

C. TRANSPARENCY
   - Setiap keputusan AI harus explainable
   - Confidence score untuk setiap analisis
   - Timeline lengkap dari submit hingga final decision
   - Visual indicators untuk suspicious patterns

D. SECURITY & PRIVACY
   - Akses terbatas untuk Admin dan Dosen saja
   - Audit log untuk setiap aktivitas verifikasi
   - Enkripsi untuk data sensitif (foto, lokasi)
   - Rate limiting untuk prevent abuse

DATA SOURCE MAPPING (Device & Location):
----------------------------------------
DEVICE INFO:
- Query: SELECT device_info FROM kehadiran WHERE id = {kehadiran_id}
- Field: kehadiran.device_info (JSON column)
- Parse JSON untuk extract:
  * device_model: device_info->device
  * os: device_info->os
  * browser: device_info->browser
  * user_agent: device_info->user_agent
  * screen_resolution: device_info->screen

NETWORK INFO:
- IP Address: kehadiran.ip_address
- ISP: Lookup via IP geolocation API
- Connection Type: device_info->connection_type

GPS LOCATION:
- Latitude: kehadiran.latitude
- Longitude: kehadiran.longitude
- Accuracy: kehadiran.accuracy
- Timestamp: kehadiran.waktu_absen

ZONE VALIDATION:
- Query: SELECT * FROM zona_presensi WHERE id = {zona_id}
- Zone Center: zona_presensi.latitude, zona_presensi.longitude
- Radius: zona_presensi.radius
- Calculate Distance: Haversine formula
  Formula: 
  a = sin²(Δlat/2) + cos(lat1) × cos(lat2) × sin²(Δlon/2)
  c = 2 × atan2(√a, √(1−a))
  distance = R × c (R = 6371 km)

```typescript
const handleScanWithAI = async (attendanceId: number) => {
    setIsScanning(true);
    setProgress(0);
    
    try {
        // Start WebSocket connection untuk real-time updates
        const ws = new WebSocket(`ws://localhost:6001/verification/${attendanceId}`);
        
        ws.onmessage = (event) => {
            const data = JSON.parse(event.data);
            setProgress(data.progress);
            setCurrentStep(data.step);
            setStepDetails(data.details);
        };
        
        // Trigger AI scan
        const response = await axios.post(`/api/dosen/verification/scan/${attendanceId}`);
        
        if (response.data.success) {
            toast.success('AI Scan completed successfully!');
            setVerificationResult(response.data.result);
        }
    } catch (error) {
        toast.error('AI Scan failed. Please try again.');
    } finally {
        setIsScanning(false);
        ws.close();
    }
};
```

```php
public function scan(Request $request, $attendanceId)
{
    // 1. Get attendance record
    $attendance = Kehadiran::with(['mahasiswa', 'sesi', 'zona'])
        ->findOrFail($attendanceId);
    
    // 2. Validate access (dosen hanya bisa verify mahasiswa di kelasnya)
    if (!$this->canVerify($attendance)) {
        return response()->json(['error' => 'Unauthorized'], 403);
    }
    
    // 3. Get reference photo from mahasiswa
    $referencePhoto = Storage::path($attendance->mahasiswa->foto_profil);
    
    // 4. Get selfie photo from attendance
    $selfiePhoto = Storage::path($attendance->selfie_path);
    
    // 5. Get historical data (last 5 verified attendances)
    $historicalData = Kehadiran::where('mahasiswa_id', $attendance->mahasiswa_id)
        ->where('status', 'verified')
        ->orderBy('waktu_absen', 'desc')
        ->limit(5)
        ->get();
    
    // 6. Get device history
    $deviceHistory = Kehadiran::where('mahasiswa_id', $attendance->mahasiswa_id)
        ->select(DB::raw('device_info->>"$.device" as device'), DB::raw('COUNT(*) as count'))
        ->groupBy('device')
        ->orderBy('count', 'desc')
        ->get();
    
    // 7. Get zone information
    $zone = $attendance->zona;
    
    // 8. Dispatch AI verification job
    $verificationId = 'VRF-' . date('Ymd') . '-' . str_pad($attendanceId, 6, '0', STR_PAD_LEFT);
    
    VerifyAttendanceJob::dispatch([
        'verification_id' => $verificationId,
        'attendance_id' => $attendanceId,
        'reference_photo' => $referencePhoto,
        'selfie_photo' => $selfiePhoto,
        'historical_data' => $historicalData,
        'device_history' => $deviceHistory,
        'zone' => $zone,
        'user_id' => auth()->id(),
    ]);
    
    return response()->json([
        'success' => true,
        'verification_id' => $verificationId,
        'message' => 'AI verification started'
    ]);
}
```

```php
class VerifyAttendanceJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;
    
    protected $data;
    
    public function handle()
    {
        $aiService = new SelfieVerificationAIService();
        
        // Log start
        $this->logStep('AI Processing Started', 'processing', 0);
        
        // Step 1: Face Detection (3 seconds)
        $this->broadcastProgress(10, 'Detecting faces...');
        $faceDetection = $aiService->detectFaces($this->data['selfie_photo']);
        $this->logStep('Face Detection Completed', 'completed', 3.2, $faceDetection);
        
        // Step 2: Face Comparison (3 seconds)
        $this->broadcastProgress(30, 'Comparing faces...');
        $faceComparison = $aiService->compareFaces(
            $this->data['reference_photo'],
            $this->data['selfie_photo']
        );
        $this->logStep('Face Comparison Completed', 'completed', 2.8, $faceComparison);
        
        // Step 3: Liveness Detection (2 seconds)
        $this->broadcastProgress(50, 'Checking liveness...');
        $liveness = $aiService->detectLiveness($this->data['selfie_photo']);
        $this->logStep('Liveness Detection Completed', 'completed', 2.5, $liveness);
        
        // Step 4: Device Validation (2 seconds)
        $this->broadcastProgress(65, 'Validating device...');
        $deviceValidation = $aiService->validateDevice(
            $this->data['attendance_id'],
            $this->data['device_history']
        );
        $this->logStep('Device Validation Completed', 'completed', 1.8, $deviceValidation);
        
        // Step 5: Location Validation (1 second)
        $this->broadcastProgress(75, 'Validating location...');
        $locationValidation = $aiService->validateLocation(
            $this->data['attendance_id'],
            $this->data['zone']
        );
        $this->logStep('Location Validation Completed', 'completed', 1.2, $locationValidation);
        
        // Step 6: Fraud Detection (2 seconds)
        $this->broadcastProgress(85, 'Detecting fraud patterns...');
        $fraudDetection = $aiService->detectFraud([
            'face_comparison' => $faceComparison,
            'liveness' => $liveness,
            'device' => $deviceValidation,
            'location' => $locationValidation,
        ]);
        $this->logStep('Fraud Detection Completed', 'completed', 2.3, $fraudDetection);
        
        // Step 7: Historical Analysis (2 seconds)
        $this->broadcastProgress(95, 'Analyzing historical data...');
        $historicalAnalysis = $aiService->analyzeHistorical(
            $this->data['historical_data'],
            $faceComparison
        );
        $this->logStep('Historical Analysis Completed', 'completed', 1.9, $historicalAnalysis);
        
        // Step 8: Final Decision (1 second)
        $this->broadcastProgress(100, 'Generating final result...');
        $finalDecision = $aiService->makeFinalDecision([
            'face_comparison' => $faceComparison,
            'liveness' => $liveness,
            'device' => $deviceValidation,
            'location' => $locationValidation,
            'fraud' => $fraudDetection,
            'historical' => $historicalAnalysis,
        ]);
        
        // Update attendance status
        $attendance = Kehadiran::find($this->data['attendance_id']);
        $attendance->status = $finalDecision['status']; // verified/rejected/needs_review
        $attendance->ai_confidence = $finalDecision['confidence'];
        $attendance->ai_analysis = json_encode($finalDecision);
        $attendance->verified_by = $this->data['user_id'];
        $attendance->verified_at = now();
        $attendance->save();
        
        $this->logStep('Final Verification Result', 'completed', 17, $finalDecision);
        $this->logStep('Data Saved to Database', 'completed', 1);
        
        // Broadcast completion
        broadcast(new VerificationCompleted($this->data['verification_id'], $finalDecision));
    }
    
    protected function broadcastProgress($percentage, $message)
    {
        broadcast(new VerificationProgress(
            $this->data['verification_id'],
            $percentage,
            $message
        ));
    }
    
    protected function logStep($stepName, $status, $duration = 0, $result = null)
    {
        VerificationLog::create([
            'verification_id' => $this->data['verification_id'],
            'kehadiran_id' => $this->data['attendance_id'],
            'step_name' => $stepName,
            'step_status' => $status,
            'duration_seconds' => $duration,
            'result_data' => $result ? json_encode($result) : null,
            'timestamp' => now(),
        ]);
    }
}
```

Service: app/Services/SelfieVerificationAIService.php

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Storage;

class SelfieVerificationAIService
{
    protected $faceApiUrl;
    protected $faceApiKey;
    
    public function __construct()
    {
        $this->faceApiUrl = config('services.face_api.url');
        $this->faceApiKey = config('services.face_api.key');
    }
    
    /**
     * Detect faces in image
     */
    public function detectFaces($imagePath)
    {
        $imageData = base64_encode(file_get_contents($imagePath));
        
        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . $this->faceApiKey,
        ])->post($this->faceApiUrl . '/detect', [
            'image' => $imageData,
            'return_landmarks' => true,
            'return_attributes' => true,
        ]);
        
        $result = $response->json();
        
        return [
            'faces_detected' => count($result['faces']),
            'confidence' => $result['faces'][0]['confidence'] ?? 0,
            'landmarks' => $result['faces'][0]['landmarks'] ?? [],
            'quality_score' => $this->calculateQualityScore($result['faces'][0]),
        ];
    }
    
    /**
     * Compare two faces
     */
    public function compareFaces($referencePhoto, $selfiePhoto)
    {
        $refData = base64_encode(file_get_contents($referencePhoto));
        $selfieData = base64_encode(file_get_contents($selfiePhoto));
        
        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . $this->faceApiKey,
        ])->post($this->faceApiUrl . '/compare', [
            'image1' => $refData,
            'image2' => $selfieData,
        ]);
        
        $result = $response->json();
        
        $similarity = $result['similarity'] * 100; // Convert to percentage
        
        return [
            'similarity_score' => round($similarity, 2),
            'euclidean_distance' => $result['distance'],
            'cosine_similarity' => $result['cosine'],
            'match_status' => $this->getMatchStatus($similarity),
            'confidence' => $result['confidence'],
        ];
    }
    
    /**
     * Detect if photo is from real person (liveness)
     */
    public function detectLiveness($imagePath)
    {
        $imageData = base64_encode(file_get_contents($imagePath));
        
        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . $this->faceApiKey,
        ])->post($this->faceApiUrl . '/liveness', [
            'image' => $imageData,
        ]);
        
        $result = $response->json();
        
        return [
            'liveness_score' => $result['liveness_score'],
            'is_real' => $result['liveness_score'] >= 60,
            'texture_analysis' => $result['texture_score'],
            'depth_perception' => $result['depth_score'],
            'screen_detection' => $result['screen_score'],
            'print_attack' => $result['print_score'],
            'risk_level' => $this->getRiskLevel($result['liveness_score']),
        ];
    }
    
    /**
     * Validate device information
     */
    public function validateDevice($attendanceId, $deviceHistory)
    {
        $attendance = \App\Models\Kehadiran::find($attendanceId);
        $currentDevice = json_decode($attendance->device_info, true);
        
        // Check if device has been used before
        $deviceUsageCount = $deviceHistory->where('device', $currentDevice['device'])->first();
        $isTrusted = $deviceUsageCount && $deviceUsageCount->count >= 3;
        
        // Check for device anomaly
        $isAnomaly = false;
        if ($deviceHistory->count() > 0) {
            $mostUsedDevice = $deviceHistory->first();
            $isAnomaly = $currentDevice['device'] !== $mostUsedDevice->device;
        }
        
        return [
            'device_model' => $currentDevice['device'],
            'os' => $currentDevice['os'],
            'browser' => $currentDevice['browser'],
            'ip_address' => $attendance->ip_address,
            'is_trusted' => $isTrusted,
            'usage_count' => $deviceUsageCount->count ?? 0,
            'is_anomaly' => $isAnomaly,
            'risk_level' => $isAnomaly ? 'MEDIUM' : 'LOW',
        ];
    }
    
    /**
     * Validate GPS location
     */
    public function validateLocation($attendanceId, $zone)
    {
        $attendance = \App\Models\Kehadiran::find($attendanceId);
        
        // Calculate distance using Haversine formula
        $distance = $this->calculateDistance(
            $attendance->latitude,
            $attendance->longitude,
            $zone->latitude,
            $zone->longitude
        );
        
        $isValid = $distance <= $zone->radius;
        
        return [
            'latitude' => $attendance->latitude,
            'longitude' => $attendance->longitude,
            'accuracy' => $attendance->accuracy,
            'zone_name' => $zone->nama,
            'zone_center' => [
                'lat' => $zone->latitude,
                'lng' => $zone->longitude,
            ],
            'distance' => round($distance, 2),
            'allowed_radius' => $zone->radius,
            'is_valid' => $isValid,
            'risk_level' => $isValid ? 'NONE' : 'HIGH',
        ];
    }
    
    /**
     * Detect fraud patterns
     */
    public function detectFraud($data)
    {
        $indicators = [];
        $riskScore = 0;
        
        // Check 1: Multiple faces
        if ($data['face_comparison']['faces_detected'] > 1) {
            $indicators[] = 'Multiple faces detected';
            $riskScore += 40;
        }
        
        // Check 2: Low similarity
        if ($data['face_comparison']['similarity_score'] < 70) {
            $indicators[] = 'Low face similarity';
            $riskScore += 40;
        }
        
        // Check 3: Liveness failed
        if (!$data['liveness']['is_real']) {
            $indicators[] = 'Liveness detection failed';
            $riskScore += 40;
        }
        
        // Check 4: Location invalid
        if (!$data['location']['is_valid']) {
            $indicators[] = 'Location outside zone';
            $riskScore += 30;
        }
        
        // Check 5: Device anomaly
        if ($data['device']['is_anomaly']) {
            $indicators[] = 'Unusual device detected';
            $riskScore += 15;
        }
        
        // Check 6: Duplicate photo
        $isDuplicate = $this->checkDuplicatePhoto($data['selfie_photo']);
        if ($isDuplicate) {
            $indicators[] = 'Photo used before';
            $riskScore += 35;
        }
        
        return [
            'risk_score' => min($riskScore, 100),
            'risk_level' => $this->getRiskLevelFromScore($riskScore),
            'indicators' => $indicators,
            'total_checks' => 8,
            'passed' => 8 - count($indicators),
            'failed' => count($indicators),
        ];
    }
    
    /**
     * Analyze historical attendance patterns
     */
    public function analyzeHistorical($historicalData, $currentComparison)
    {
        $similarities = [];
        
        foreach ($historicalData as $record) {
            $similarity = $this->compareFaces(
                $record->selfie_path,
                $currentComparison['selfie_photo']
            );
            $similarities[] = $similarity['similarity_score'];
        }
        
        $avgSimilarity = count($similarities) > 0 ? array_sum($similarities) / count($similarities) : 0;
        $stdDev = $this->calculateStdDev($similarities);
        
        return [
            'previous_photos' => count($historicalData),
            'similarities' => $similarities,
            'average_similarity' => round($avgSimilarity, 2),
            'std_deviation' => round($stdDev, 2),
            'consistency_score' => $this->calculateConsistencyScore($stdDev),
            'is_consistent' => $stdDev < 5, // Low deviation = consistent
        ];
    }
    
    /**
     * Make final verification decision
     */
    public function makeFinalDecision($data)
    {
        $scores = [
            'face_match' => $data['face_comparison']['similarity_score'],
            'liveness' => $data['liveness']['liveness_score'],
            'location' => $data['location']['is_valid'] ? 100 : 0,
            'device' => $data['device']['is_trusted'] ? 100 : 50,
            'fraud' => 100 - $data['fraud']['risk_score'],
            'historical' => $data['historical']['consistency_score'],
        ];
        
        // Weighted average
        $weights = [
            'face_match' => 0.35,
            'liveness' => 0.25,
            'location' => 0.15,
            'device' => 0.10,
            'fraud' => 0.10,
            'historical' => 0.05,
        ];
        
        $overallConfidence = 0;
        foreach ($scores as $key => $score) {
            $overallConfidence += $score * $weights[$key];
        }
        
        // Decision logic
        $status = 'needs_review';
        $recommendation = 'Manual review required';
        
        if ($data['fraud']['risk_score'] >= 60) {
            $status = 'rejected';
            $recommendation = 'Auto-reject due to high fraud risk';
        } elseif ($overallConfidence >= 85 && $data['fraud']['risk_score'] < 30) {
            $status = 'verified';
            $recommendation = 'Safe to approve automatically';
        }
        
        return [
            'status' => $status,
            'confidence' => round($overallConfidence, 2),
            'recommendation' => $recommendation,
            'scores' => $scores,
            'weights' => $weights,
            'details' => $data,
        ];
    }
    
    // Helper methods
    protected function calculateDistance($lat1, $lon1, $lat2, $lon2)
    {
        $earthRadius = 6371000; // meters
        
        $dLat = deg2rad($lat2 - $lat1);
        $dLon = deg2rad($lon2 - $lon1);
        
        $a = sin($dLat/2) * sin($dLat/2) +
             cos(deg2rad($lat1)) * cos(deg2rad($lat2)) *
             sin($dLon/2) * sin($dLon/2);
        
        $c = 2 * atan2(sqrt($a), sqrt(1-$a));
        
        return $earthRadius * $c;
    }
    
    protected function getMatchStatus($similarity)
    {
        if ($similarity >= 85) return 'VERIFIED';
        if ($similarity >= 70) return 'NEEDS_REVIEW';
        return 'REJECTED';
    }
    
    protected function getRiskLevel($score)
    {
        if ($score >= 80) return 'LOW';
        if ($score >= 60) return 'MEDIUM';
        return 'HIGH';
    }
    
    protected function getRiskLevelFromScore($score)
    {
        if ($score >= 60) return 'HIGH';
        if ($score >= 30) return 'MEDIUM';
        return 'LOW';
    }
    
    protected function calculateStdDev($values)
    {
        $count = count($values);
        if ($count === 0) return 0;
        
        $mean = array_sum($values) / $count;
        $variance = array_sum(array_map(function($x) use ($mean) {
            return pow($x - $mean, 2);
        }, $values)) / $count;
        
        return sqrt($variance);
    }
    
    protected function calculateConsistencyScore($stdDev)
    {
        // Lower std dev = higher consistency
        return max(0, 100 - ($stdDev * 10));
    }
}
```

5.2 FRAUD DETECTION INDICATORS
-------------------------------

8 CHECKS yang dilakukan untuk mendeteksi fraud:

5.3 RISK SCORING SYSTEM
------------------------

Total Risk Score = Sum of all failed checks (max 100)

Risk Level Classification:
┌──────────────────────────────────────────────────────────────┐
│  Score Range  │  Risk Level  │  Color  │  Action            │
├──────────────────────────────────────────────────────────────┤
│  0-29         │  🟢 LOW      │  Green  │  Auto-approve      │
│  30-59        │  🟡 MEDIUM   │  Yellow │  Manual review     │
│  60-100       │  🔴 HIGH     │  Red    │  Auto-reject       │
└──────────────────────────────────────────────────────────────┘

Example Scenarios:

SCENARIO 1: Perfect Attendance
- All checks passed
- Risk Score: 0
- Risk Level: LOW
- Decision: AUTO-APPROVE

SCENARIO 2: Minor Issues
- Device anomaly detected (15 points)
- Photo quality slightly low (10 points)
- Risk Score: 25
- Risk Level: LOW
- Decision: AUTO-APPROVE (with warning)

SCENARIO 3: Moderate Concerns
- Face similarity 75% (borderline)
- Device anomaly (15 points)
- Location accuracy poor (10 points)
- Risk Score: 40
- Risk Level: MEDIUM
- Decision: NEEDS MANUAL REVIEW

SCENARIO 4: High Risk
- Face similarity 65% (40 points)
- Liveness failed (40 points)
- Risk Score: 80
- Risk Level: HIGH
- Decision: AUTO-REJECT

5.4 CONFIDENCE CALCULATION
---------------------------

Overall Confidence = Weighted Average of all scores

Weights:
- Face Match: 35%
- Liveness: 25%
- Location: 15%
- Device: 10%
- Fraud: 10%
- Historical: 5%

Formula:
Confidence = (FaceMatch × 0.35) + (Liveness × 0.25) + (Location × 0.15) + 
             (Device × 0.10) + ((100 - FraudScore) × 0.10) + (Historical × 0.05)

Example:
- Face Match: 87.5%
- Liveness: 91%
- Location: 100% (valid)
- Device: 100% (trusted)
- Fraud: 15 (so 85%)
- Historical: 89.6%

Confidence = (87.5 × 0.35) + (91 × 0.25) + (100 × 0.15) + 
             (100 × 0.10) + (85 × 0.10) + (89.6 × 0.05)
           = 30.625 + 22.75 + 15 + 10 + 8.5 + 4.48
           = 91.355%

Result: 91.4% confidence → AUTO-APPROVE

```typescript
import { useEffect, useState } from 'react';
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

// Initialize Laravel Echo
window.Pusher = Pusher;
window.Echo = new Echo({
    broadcaster: 'pusher',
    key: import.meta.env.VITE_PUSHER_APP_KEY,
    cluster: import.meta.env.VITE_PUSHER_APP_CLUSTER,
    forceTLS: true,
});

const useVerificationProgress = (verificationId: string) => {
    const [progress, setProgress] = useState(0);
    const [currentStep, setCurrentStep] = useState('');
    const [steps, setSteps] = useState<ProgressStep[]>([]);
    
    useEffect(() => {
        if (!verificationId) return;
        
        // Listen for progress updates
        window.Echo.channel(`verification.${verificationId}`)
            .listen('VerificationProgress', (e: any) => {
                setProgress(e.progress);
                setCurrentStep(e.step);
                
                // Update steps array
                setSteps(prev => {
                    const newSteps = [...prev];
                    const stepIndex = newSteps.findIndex(s => s.name === e.step);
                    if (stepIndex >= 0) {
                        newSteps[stepIndex].status = 'processing';
                        newSteps[stepIndex].progress = e.progress;
                    }
                    return newSteps;
                });
            })
            .listen('VerificationStepCompleted', (e: any) => {
                setSteps(prev => {
                    const newSteps = [...prev];
                    const stepIndex = newSteps.findIndex(s => s.name === e.step);
                    if (stepIndex >= 0) {
                        newSteps[stepIndex].status = 'completed';
                        newSteps[stepIndex].duration = e.duration;
                    }
                    return newSteps;
                });
            })
            .listen('VerificationCompleted', (e: any) => {
                setProgress(100);
                // Handle completion
            });
        
        return () => {
            window.Echo.leave(`verification.${verificationId}`);
        };
    }, [verificationId]);
    
    return { progress, currentStep, steps };
};
```

```php
// Middleware: CheckVerificationAccess
class CheckVerificationAccess
{
    public function handle($request, Closure $next)
    {
        $user = auth()->user();
        $attendanceId = $request->route('id');
        
        // Admin has full access
        if ($user->role === 'admin') {
            return $next($request);
        }
        
        // Dosen can only access their students
        if ($user->role === 'dosen') {
            $attendance = Kehadiran::with('sesi.mataKuliah')->find($attendanceId);
            
            if (!$attendance) {
                abort(404);
            }
            
            // Check if dosen teaches this class
            if ($attendance->sesi->mataKuliah->dosen_id !== $user->id) {
                abort(403, 'Unauthorized: You can only verify your own students');
            }
            
            return $next($request);
        }
        
        // Mahasiswa cannot access verification page
        abort(403, 'Unauthorized: Students cannot access verification');
    }
}

// Apply middleware to routes
Route::middleware(['auth', 'check.verification.access'])->group(function () {
    Route::get('/dosen/verification', [VerificationController::class, 'index']);
    Route::get('/dosen/verification/{id}', [VerificationController::class, 'show']);
    Route::post('/dosen/verification/scan/{id}', [VerificationController::class, 'scan']);
    Route::post('/dosen/verification/approve/{id}', [VerificationController::class, 'approve']);
    Route::post('/dosen/verification/reject/{id}', [VerificationController::class, 'reject']);
});
```

7.7 API AUTHENTICATION
----------------------

Secure AI API calls:

```php
// config/services.php
return [
    'face_api' => [
        'url' => env('FACE_API_URL'),
        'key' => env('FACE_API_KEY'),
        'secret' => env('FACE_API_SECRET'),
    ],
];

// Service: FaceAPIClient
class FaceAPIClient
{
    protected function getAuthHeaders()
    {
        $timestamp = time();
        $signature = hash_hmac(
            'sha256',
            $timestamp . config('services.face_api.key'),
            config('services.face_api.secret')
        );
        
        return [
            'Authorization' => 'Bearer ' . config('services.face_api.key'),
            'X-Timestamp' => $timestamp,
            'X-Signature' => $signature,
        ];
    }
    
    public function makeRequest($endpoint, $data)
    {
        $response = Http::withHeaders($this->getAuthHeaders())
            ->timeout(30)
            ->retry(3, 1000)
            ->post(config('services.face_api.url') . $endpoint, $data);
        
        if ($response->failed()) {
            throw new \Exception('Face API request failed: ' . $response->body());
        }
        
        return $response->json();
    }
}
```
