1.1 TUJUAN UTAMA SISTEM
------------------------
Membangun sistem penilaian kehadiran mahasiswa yang SANGAT CANGGIH dengan fitur:
- Kalkulasi otomatis nilai kehadiran berdasarkan presensi real-time
- Sistem grading A-E dengan threshold yang dapat dikonfigurasi
- Analisis mendalam per mahasiswa dengan riwayat lengkap
- Export data ke multiple format (CSV, PDF, Excel)
- Filter dan pencarian advanced dengan multiple criteria
- Visualisasi statistik dan distribusi nilai

- Prediksi kelayakan UAS berdasarkan attendance rate
- Real-time updates saat ada perubahan data presensi

------------------
A. AUTOMATIC CALCULATION
   - Nilai dihitung otomatis dari data presensi real
   - Update real-time saat ada perubahan status kehadiran
   - Formula transparan dan dapat diaudit
   - Tidak ada manual input nilai (kecuali override)

B. FAIRNESS & TRANSPARENCY
   - Setiap mahasiswa dapat melihat detail perhitungan nilai mereka
   - Kriteria penilaian jelas dan konsisten
   - Audit trail lengkap untuk setiap perubahan

C. FLEXIBILITY
   - Threshold nilai dapat dikonfigurasi per mata kuliah
   - Bobot kehadiran dapat disesuaikan
   - Support multiple grading systems (A-E, 0-100, Pass/Fail)
   - Custom rules untuk kasus khusus

D. ANALYTICS & INSIGHTS
   - Statistik distribusi nilai real-time
   - Identifikasi mahasiswa at-risk
   - Trend analysis kehadiran
   - Comparison antar kelas/semester

2.1 SISTEM POIN KEHADIRAN
--------------------------

POIN PER STATUS KEHADIRAN:
┌─────────────────────────────────────────────────────────────────────────┐
│  Status          │  Poin  │  Keterangan                                 │
├─────────────────────────────────────────────────────────────────────────┤
│  present         │  100   │  Hadir tepat waktu                          │
│  late            │  75    │  Hadir terlambat (< 15 menit)               │
│  permit          │  50    │  Izin dengan surat resmi                    │
│  sick            │  50    │  Sakit dengan surat dokter                  │
│  absent          │  0     │  Tidak hadir tanpa keterangan               │
│  rejected        │  0     │  Presensi ditolak (fraud/invalid)           │
└─────────────────────────────────────────────────────────────────────────┘

CATATAN PENTING:
- Poin dapat dikonfigurasi per mata kuliah di settings
- Late threshold (15 menit) dapat disesuaikan
- Permit dan sick memerlukan dokumen pendukung
- Rejected tidak dihitung dalam total sessions

2.2 FORMULA PERHITUNGAN NILAI AKHIR
------------------------------------

STEP 1: Hitung Total Poin
--------------------------
Total Poin = Σ (Poin per Pertemuan)

Contoh:
Pertemuan 1: present (100)
Pertemuan 2: late (75)
Pertemuan 3: present (100)
Pertemuan 4: sick (50)
Pertemuan 5: absent (0)
Total Poin = 100 + 75 + 100 + 50 + 0 = 325

STEP 2: Hitung Maksimum Poin Possible
--------------------------------------
Max Poin = Total Pertemuan × 100

Contoh:
Total Pertemuan = 5
Max Poin = 5 × 100 = 500

STEP 3: Hitung Persentase Kehadiran
------------------------------------
Attendance Rate = (Total Poin / Max Poin) × 100

Contoh:
Attendance Rate = (325 / 500) × 100 = 65%

STEP 4: Hitung Rata-rata Poin
------------------------------
Average Points = Total Poin / Total Pertemuan

Contoh:
Average Points = 325 / 5 = 65

STEP 5: Konversi ke Nilai Huruf (Grade Letter)
-----------------------------------------------
Berdasarkan Attendance Rate:

┌─────────────────────────────────────────────────────────────────────────┐
│  Attendance Rate  │  Grade  │  Keterangan                               │
├─────────────────────────────────────────────────────────────────────────┤
│  >= 90%           │  A      │  Excellent - Sangat Baik                  │
│  80% - 89%        │  B      │  Good - Baik                              │
│  70% - 79%        │  C      │  Satisfactory - Cukup                     │
│  60% - 69%        │  D      │  Poor - Kurang                            │
│  < 60%            │  E      │  Fail - Gagal                             │
└─────────────────────────────────────────────────────────────────────────┘

Contoh:
Attendance Rate = 65%
Grade = D (Poor)

STEP 6: Tentukan Kelayakan UAS
-------------------------------
Mahasiswa dapat mengikuti UAS jika:
- Attendance Rate >= 75% (threshold default)
- ATAU memiliki izin/sakit yang valid untuk absence

Formula:
can_take_uas = (attendance_rate >= 75) OR (valid_permits >= required_permits)

Contoh:
Attendance Rate = 65% (< 75%)
Valid Permits = 0
can_take_uas = FALSE (Tidak bisa UAS)

2.3 FORMULA ALTERNATIF (WEIGHTED SYSTEM)
-----------------------------------------

Untuk sistem yang lebih kompleks, dapat menggunakan weighted scoring:

Nilai Akhir = (Kehadiran × 40%) + (Tugas × 30%) + (UTS × 15%) + (UAS × 15%)

Dimana:
- Kehadiran = Attendance Rate (dari formula di atas)
- Tugas = Rata-rata nilai tugas
- UTS = Nilai Ujian Tengah Semester
- UAS = Nilai Ujian Akhir Semester

Contoh:
Kehadiran = 85% → 85 × 0.4 = 34
Tugas = 80 → 80 × 0.3 = 24
UTS = 75 → 75 × 0.15 = 11.25
UAS = 90 → 90 × 0.15 = 13.5
Nilai Akhir = 34 + 24 + 11.25 + 13.5 = 82.75 → Grade B

2.4 SPECIAL CASES & EDGE CASES
-------------------------------

CASE 1: Mahasiswa Join Late (Masuk Terlambat)
----------------------------------------------
Jika mahasiswa join setelah beberapa pertemuan:
- Hanya hitung pertemuan setelah join date
- Max Poin = (Total Pertemuan - Missed Before Join) × 100
- Tidak penalize untuk pertemuan sebelum join

CASE 2: Pertemuan Dibatalkan (Class Cancelled)
-----------------------------------------------
Jika pertemuan dibatalkan oleh dosen:
- Tidak dihitung dalam Total Pertemuan
- Tidak affect Max Poin
- Status = "cancelled" (tidak masuk perhitungan)

CASE 3: Override Manual
-----------------------
Jika dosen melakukan override status:
- Gunakan poin dari status baru
- Simpan audit trail (old status, new status, reason, timestamp)
- Recalculate semua nilai terkait
- Notify mahasiswa tentang perubahan

CASE 4: Mahasiswa Cuti/Drop
----------------------------
Jika mahasiswa cuti atau drop:
- Status = "inactive"
- Tidak masuk dalam perhitungan statistik kelas
- Nilai di-freeze pada saat cuti/drop
- Dapat di-reactivate jika kembali

CASE 5: Remedial/Makeup
-----------------------
Jika ada remedial untuk absence:
- Mahasiswa dapat submit makeup assignment
- Jika approved, status berubah dari absent → permit
- Poin berubah dari 0 → 50
- Recalculate nilai otomatis
